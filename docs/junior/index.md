# Junior Roadmap

Mục tiêu của phần Junior là giúp bạn xây được một ứng dụng web fullstack cơ bản, hiểu từng phần chính trong hệ thống và biết cách đưa sản phẩm lên môi trường chạy thật.

## Năng lực cần đạt

| Nhóm | Kết quả mong muốn |
| --- | --- |
| Backend | Viết được REST API bằng ASP.NET Core, hiểu middleware, DI, EF Core, LINQ và JWT |
| Frontend | Xây được UI React có routing, form, component, hooks và state cơ bản |
| Database | Thiết kế bảng đơn giản, hiểu transaction, isolation, index và query optimization cơ bản |
| Testing | Biết viết unit test và integration test cho flow quan trọng |
| Deployment | Deploy được frontend, backend và database lên cloud service phổ biến |

## Thứ tự học gợi ý

1. Backend trước để hiểu API, database access và authentication.
2. Frontend sau đó để gọi API, xử lý UI state và routing.
3. Database song song với backend, đặc biệt là transaction và index.
4. Testing trước khi deploy để giảm lỗi regression.
5. Deployment cuối cùng để hoàn thiện vòng đời từ source code đến sản phẩm chạy thật.

## Checklist hoàn thành Junior

- Tạo được ASP.NET Core Web API có controller, service, repository và DTO.
- Dùng EF Core migration để tạo và cập nhật database.
- Viết được API đăng nhập, phát JWT và bảo vệ endpoint.
- Xây được React app có route, form, loading, error và state cơ bản.
- Hiểu khi nào cần transaction và khi nào cần index.
- Có ít nhất một unit test và một integration test cho flow quan trọng.
- Deploy được frontend, backend và database, cấu hình environment variable đúng.
