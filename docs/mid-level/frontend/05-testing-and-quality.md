# Frontend Testing & Quality

## Mục tiêu

Đảm bảo UI quan trọng hoạt động đúng khi refactor hoặc thêm feature mới.

## Cần nắm

- Unit test cho utility.
- Component test.
- Hook test.
- Integration test cho user flow.
- Mock API.
- Accessibility basic.
- Lint, format, type checking.

## Checklist

- Test theo hành vi người dùng, không test implementation detail.
- Form có test validation.
- API error state được test.
- Component quan trọng có accessibility label phù hợp.
- CI chạy lint, type check và test.

## Bài thực hành

- Test form login với valid/invalid input.
- Mock API product list.
- Test flow search + pagination.
