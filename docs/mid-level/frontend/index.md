# ⚛️ Mid-Level Frontend Roadmap

Ở mid-level, frontend không chỉ là render UI. Bạn cần biết tổ chức component, quản lý state, fetch data hiệu quả, tối ưu performance và đảm bảo chất lượng bằng test.

## Nên tập trung

| Topic | Mục tiêu |
| --- | --- |
| Component Architecture | Tách component dễ tái sử dụng và dễ maintain |
| State Management | Biết state nào đặt local, global hoặc server |
| Data Fetching & Cache | Fetch API có loading, error, cache, revalidate |
| Frontend Performance | Giảm render thừa, tối ưu bundle và UX |
| Testing & Quality | Test component, form, hook và user flow |

## Lộ trình gợi ý

1. Tổ chức component và folder structure.
2. Phân loại state trong ứng dụng.
3. Học data fetching/cache với React Query hoặc SWR.
4. Tối ưu render và bundle.
5. Viết test cho component và flow quan trọng.
