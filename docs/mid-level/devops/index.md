# 🌐 Mid-Level DevOps Roadmap

Ở mid-level, DevOps nên tập trung vào khả năng đưa ứng dụng từ code lên môi trường chạy thật một cách lặp lại được, quan sát được và ít lỗi thủ công.

## Nên tập trung

| Topic | Mục tiêu |
| --- | --- |
| CI/CD Pipeline | Tự động build, test, deploy |
| Docker Compose & Environment | Chạy stack local/staging nhất quán |
| Nginx Reverse Proxy | Routing, SSL, static file, reverse proxy |
| Observability & Logging | Log, metric, health check, alert |
| Deployment Strategy | Rollback, blue-green, rolling deployment |

## Lộ trình gợi ý

1. Chuẩn hóa Dockerfile và Docker Compose.
2. Tạo pipeline build/test/deploy.
3. Dùng Nginx làm reverse proxy.
4. Thêm health check, log và monitoring.
5. Học rollback và deployment strategy.
