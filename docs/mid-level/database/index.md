# 🗄️ Mid-Level Database Roadmap

Ở mid-level, database cần được học theo hướng thiết kế đúng, query hiệu quả, transaction an toàn và vận hành ổn định.

## Nên tập trung

| Topic | Mục tiêu |
| --- | --- |
| Schema Design | Thiết kế table, relationship và constraint hợp lý |
| Indexing & Query Plan | Tối ưu query dựa trên execution plan |
| Transactions & Concurrency | Tránh race condition và hiểu lock/isolation |
| Migrations & Versioning | Quản lý thay đổi schema an toàn |
| Database Performance | Theo dõi slow query, connection pool và growth |

## Lộ trình gợi ý

1. Ôn lại schema design và normalization.
2. Học index dựa trên query pattern.
3. Hiểu transaction, lock và concurrency.
4. Quản lý migration trong team.
5. Theo dõi performance và capacity.
